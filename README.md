# Pruebas-de-aplicaciones-m-viles
Proyecto de QA Manual desarrollado en TripleTen, enfocado en pruebas de la aplicación móvil Urban Scooter. Diseñé y ejecuté casos de prueba funcionales, positivos y negativos; validé inicio de sesión, notificaciones y conectividad. Utilicé Android Studio para las pruebas y Jira para documentar defectos, evidencias y resultados de manera detallada
